SECNOTE 1.2 — ПОЛНАЯ ИНСТРУКЦИЯ ПО ОБНОВЛЕНИЮ ЧЕРЕЗ GITHUB

ВАЖНО: эта инструкция рассчитана на репозиторий, в котором уже находится SecNote 1.1. Package ID infernics.notes и debug-подпись сохранены. APK 1.2 должен устанавливаться поверх 1.1 без удаления приложения и без стирания локальных данных.

1. СКАЧАТЬ И РАСПАКОВАТЬ
- Скачайте SecNote-GitHub-Android-v1.2.zip.
- Распакуйте архив. Внутри находится папка SecNote-Android.

2. ОБНОВИТЬ ФАЙЛЫ В СУЩЕСТВУЮЩЕМ РЕПОЗИТОРИИ
- Откройте свой репозиторий GitHub (тот, где сейчас SecNote 1.1).
- Выберите Add file -> Upload files.
- Перетащите содержимое папки SecNote-Android, а не сам ZIP.
- GitHub предложит добавить новые файлы и заменить совпадающие. Подтвердите загрузку.
- Обязательно обновите app/src/main/java/infernics/notes/ и app/build.gradle.kts.
- Не удаляйте signing/secure-notes-debug.keystore. Он обеспечивает ту же подпись APK, что и в версии 1.1.
- Скрытая папка .github в существующем репозитории уже должна быть настроена. Если она не видна на форме загрузки, не нужно создавать дубликат workflow.
- Нажмите Commit changes в ветку main.

3. ПОЛУЧИТЬ APK
- Откройте вкладку Actions.
- Выберите самый последний запуск Build SecNote APK.
- Дождитесь зелёной галочки.
- Откройте запуск и скачайте Artifacts -> app-debug.apk.
- Установите APK поверх SecNote 1.1. Не удаляйте старую версию перед обновлением.

4. ЧТО ИЗМЕНИЛОСЬ В 1.2
- Кнопка + сначала предлагает «Обычная заметка» или «Список».
- Обычная заметка содержит заголовок и текст, без чек-листа под ней.
- Список — отдельный тип записи. Каждый пункт — отдельная строка с чекбоксом. Кнопка «Добавить строку» создаёт новую строку.
- Старые записи с заполненными чек-листами из 1.1 автоматически распознаются как отдельный тип «Список».
- В хранилище фото показываются плитками в галерее. Нажатие открывает увеличенный просмотр; доступны экспорт и удаление.
- Документы и остальные файлы показываются ниже отдельным списком.
- Из интерфейса удалена фраза о доступе к интернету.

5. ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
- На главном экране нажмите +: увидьте два варианта.
- Создайте обычную заметку и проверьте отсутствие блока чек-листа.
- Создайте список, добавьте несколько строк, отметьте одну или две галочками, сохраните и откройте снова.
- Добавьте фото и PDF в файловое хранилище: фотографии должны быть вверху галереей, PDF — ниже списком.
- Откройте фото, проверьте экспорт и удаление.
- Проверьте вход по паролю, биометрию и автоблокировку.

ПАРАМЕТРЫ ВЕРСИИ
- Имя: SecNote
- Package ID: infernics.notes
- Version: 1.2
- Version code: 3
- Min Android: 8.0 / API 26

БЕЗОПАСНОСТЬ
В архиве находится debug-keystore, используемый для подписи личных APK. Рекомендуется держать GitHub-репозиторий Private. Если файл ключа уже публиковался в публичном репозитории, его пароль и ключ следует считать раскрытыми для подписи APK; смена ключа не позволит установить новую сборку поверх текущей без удаления старого приложения. Это не раскрывает ключ шифрования заметок, который создаётся отдельно на устройстве.

ЕСЛИ СБОРКА НЕ УДАЛАСЬ
Откройте последний запуск Actions -> шаг Run unit tests and build APK. Пришлите лог от первой строки e: или What went wrong до конца.
